# Настройка Яндекс карт в попапе адреса доставки

## Описание

В попап выбора адреса доставки интегрирована Яндекс карта с геокодером. Пользователи могут:

- Вводить адрес в текстовое поле с автодополнением
- Кликать по карте для выбора точки
- Перетаскивать маркер для точного позиционирования
- Использовать текущее местоположение
- Получать адрес по координатам через геокодер

## Настройка API ключа

### 1. Получение API ключа

1. Перейдите на [Яндекс.Разработчик](https://developer.tech.yandex.ru/)
2. Создайте новый проект или выберите существующий
3. Включите API "JavaScript API и HTTP Геокодер"
4. Скопируйте полученный API ключ

### 2. Установка API ключа

В файле `widget_types/hte_cart/snippet.liquid` найдите строку:

```html
<script src="https://api-maps.yandex.ru/2.1/?apikey=YOUR_API_KEY&lang=ru_RU" defer></script>
```

API ключ уже установлен в коде:

```html
<script src="https://api-maps.yandex.ru/2.1/?apikey=2c44df6f-4683-4d28-97c4-5420c76f1c52&lang=ru_RU" defer></script>
```

## Функциональность

### Основные возможности

1. **Поиск по адресу**
   - Ввод адреса в текстовое поле
   - Автодополнение с подсказками
   - Поиск по нажатию Enter или кнопки поиска

2. **Выбор на карте**
   - Клик по карте для выбора точки
   - Перетаскивание маркера для точного позиционирования
   - Автоматическое получение адреса по координатам

3. **Геолокация**
   - Кнопка "Мое местоположение"
   - Автоматическое определение текущих координат
   - Центрирование карты на текущем местоположении

4. **UI элементы**
   - Поле ввода с поиском
   - Интерактивная карта
   - Отображение выбранного адреса
   - Кнопка подтверждения

### Структура файлов

- `widget_types/hte_cart/snippet.liquid` - HTML разметка попапа
- `assets/js/address-popup.js` - JavaScript логика работы с картой
- `widget_types/hte_cart/snippet.scss` - CSS стили для попапа

### API методы

Класс `AddressPopupManager` предоставляет следующие публичные методы:

```javascript
// Проверка открыт ли попап
addressPopupManager.isOpen()

// Принудительное закрытие попапа
addressPopupManager.forceClose()

// Получение выбранного адреса
const addressData = addressPopupManager.getSelectedAddress()
// Возвращает: { address: "адрес", coordinates: [lat, lng] }
```

## Настройка центра карты

По умолчанию карта центрируется на Москве. Для изменения центра карты отредактируйте файл `assets/js/address-popup.js`:

```javascript
// Центр по умолчанию - Москва
const defaultCenter = [55.7558, 37.6176]; // [широта, долгота]
```

## Стилизация

Все стили находятся в файле `widget_types/hte_cart/snippet.scss`. Основные классы:

- `.address-popup` - основной контейнер попапа
- `.popup-content` - содержимое попапа
- `.map-section` - секция с картой
- `.yandex-map` - контейнер карты
- `.address-input` - поле ввода адреса
- `.address-suggestions` - подсказки адресов
- `.selected-address-section` - секция с выбранным адресом

## Мобильная адаптация

Попап адаптирован для мобильных устройств:

- Уменьшенная высота карты на мобильных
- Вертикальное расположение элементов управления
- Полноширинные кнопки
- Адаптивные отступы

## Обработка ошибок

JavaScript код включает обработку следующих ошибок:

- Отсутствие API Яндекс карт
- Ошибки геолокации
- Ошибки геокодирования
- Отсутствие элементов DOM

Все ошибки логируются в консоль браузера для отладки.

## Браузерная совместимость

- Chrome 60+
- Firefox 55+
- Safari 12+
- Edge 79+

Требуется поддержка:
- ES6 классов
- Promises
- Geolocation API
- CSS Grid/Flexbox

## Производительность

- Карта инициализируется только при открытии попапа
- Ленивая загрузка API Яндекс карт
- Дебаунсинг для поиска адресов
- Ограничение количества подсказок (5 штук)

## Безопасность

- API ключ должен быть ограничен доменами вашего сайта
- Не передавайте API ключ в клиентском коде в открытом виде
- Используйте HTTPS для работы с геолокацией
